# Gare Cornavin Comparison Images

Place your two Google Drive images in this directory:
1. `cornavin-current.jpg` - The current status quo of Gare de Genève-Cornavin (mineral, asphalt, heat-trapping surfaces).
2. `cornavin-adapted.jpg` - The climate-resilient future vision of Gare Cornavin (permeable ground, green sedum roofs, canopy shade, bioswales).

Alternatively, you can load any JPEG image directly while previewing the website using the **"Load Before/After JPEGs"** button located on the top right of the comparison tool!
