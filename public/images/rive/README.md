# Images pour le Rond-point de Rive

Placez ici vos photos avant / après :
- `rive-before.jpg` : Photo actuelle (asphalte noir, rails sur goudron, abribus non végétalisés).
- `rive-after.jpg` : Vision adaptée (rails de tram engazonnés/sedum, abris bus à toitures végétalisées, arbres d'ombrage).

Elles seront automatiquement affichées dans l'outil de comparaison visuelle interactif.
Vous pouvez également les charger directement depuis l'interface via le bouton "Load JPEGs".
